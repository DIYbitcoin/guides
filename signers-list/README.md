# 🗂️ All DIY signers

Every open source DIY signer, the boards it runs on, where its code
lives and where to ask questions about it.

## 📟 Every signer and its boards

| Signer | Boards | Chip | ESP32-P4 |
|---|---|---|---|
| Krux | M5StickV, Maix Amigo, Maix Dock, Maix Cube, Yahboom, WonderMV, TZT, Embed Fire, WonderK PRO | K210 | In development |
| Jade | TTGO T-Display, M5Stack, ESP32-CAM, Waveshare boards and more | ESP32, ESP32-S3 | |
| SeedSigner | Raspberry Pi Zero | Raspberry Pi | Works, not released |
| ShieldSigner | Raspberry Pi Zero, Luckfox Pico | Raspberry Pi, Rockchip | |
| Specter-DIY | STM32F469 discovery board | STM32 | In development |
| Satochip-DIY | J3H145 or J3R180 javacard | Smartcard | |
| Kern | Waveshare ESP32-P4 touch boards, Elecrow CrowPanel | ESP32-P4 | Runs today |
| KISS Signer | Guition 4.3 inch, Waveshare 3.5 inch, Guition 7 inch | ESP32-P4 | Runs today |
